# SKU — IoTextra Analog

```
040401vvvtc2
```

| Field | Description |
|---|---|
| `040401` | Product code — IoTextra Analog |
| `vvv` | Version (e.g. 311 = version 3.11) |
| `t` | Type |
| `c` | Communication |
| `2` | Fixed — ADS1115 ADC chip |

**Type (t):**

| Value | Description |
|---|---|
| 0 | Pro |
| 9 | Lite |

**Communication (c):**

| Value | Description |
|---|---|
| 1 | HOST-12 connector |
| 2 | HOST-12 connector and two I²C connectors |
