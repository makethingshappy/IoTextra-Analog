# SKU — IoTextra Analog3

```
040403vvvtc5
```

| Field | Description |
|---|---|
| `040403` | Product code — IoTextra Analog3 |
| `vvv` | Version (e.g. 302 = version 3.02) |
| `t` | Type |
| `c` | Communication |
| `5` | Fixed — ADS7828 ADC chip |

**Type (t):**

| Value | Description |
|---|---|
| 0 | Pro |
| 9 | Lite |

**Communication (c):**

| Value | Description |
|---|---|
| 1 | HOST-12 connector |
| 2 | HOST-12 connector and two I²C connectors |
